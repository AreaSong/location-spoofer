# v1.2.0.0

发布日期：2026-10-10

## 主要更新

- 路线新增「赛车」出行方式，默认 100 km/h，可选 100 / 300 / 1000 / 10000，上限 10,000 km/h；手输时速若超出当前方式范围，会自动切到匹配的步行、骑行、驾车或赛车（播放中锁定路线编辑时除外）。
- 设置新增「平滑巡航切换」和「弯道自适应减速与拟真微扰」，均默认关闭。开启巡航后，已定点状态下换到 50 米–500 公里外的新地点会在 1.4 秒内缓移；路线激活仍瞬移到起点。开启弯道拟真后，路线播放在拐弯附近降速并附加轻微速度抖动。
- 「定点／路线」改到底部卡片标题内切换；路线进行中「路线」带绿色角标。路线卡用「已存」打开原有已存路线列表，速度、出行方式和循环参数直接显示在卡片内。
- 收藏排序增加「智能时段」：按名称关键词在早间提前公司类地点、晚间提前家类地点；首页收藏条会显示对应时段图标。默认仍按时间。
- 坐标点击改为自绘菜单切换并复制国内／国际坐标，避免叠在地图上的系统菜单第二次点击被吃掉。定点时坐标旁「功能」打开真实走动浮层；路线时该入口隐藏。
- 缩放控件可点按或按住连续缩放；卫星／混合图层下地图工具对比更强；选点图钉在拖动时会抬起并在松手时回落。

## 兼容性说明

- Live Activity 需要 iOS 16.2 及以上；更低系统仍可使用 App 内定点与路线功能。
- 开发者隧道模式需要 iOS 18 及以上，并依赖 LocalDevVPN 与一次电脑配对。这台手机必须作为客户端连着 Wi-Fi（无公网也可以）；只开流量或自己开热点通常连不上。
- iOS 27 beta 6 起系统禁止对 `gs-loc.apple.com` 进行 MITM 拦截，APP 模式与第三方代理模式在该版本及之后不可用。请改用开发者隧道模式。

## 自签安装

- Release 附件为未签名 IPA，安装前需要自行签名。
- 可使用免费 Apple ID 和 Impactor 完成签名安装，无需付费开发者账号。
- 签名时请保留 Bundle ID `com.paopaolabs.location-spoofer`、App Group `group.com.paopaolabs.location-spoofer` 及原有 entitlements。
- 免费 Apple ID 签名通常只有 7 天有效期，到期后需要重新签名安装。
