# v1.0.7

发布日期：2026-09-26

## 主要更新

- 新增灵动岛 / 锁屏 Live Activity：定点定位和路线行走使用两套独立布局，可在紧凑态、展开态和锁屏查看状态，并从岛上执行切换到此处、暂停、继续、停止路线、停止虚拟定位或失败后重试。
- 主动暂停与系统异常暂停分开展示；停止路线不会被写成停止虚拟定位。主应用与 Live Activity 插件的版本号已对齐。
- 新增开发者隧道模式：不拦截网络请求，通过 LocalDevVPN 调用系统开发者定位模拟（iOS 18+），支持定点推送和路线播放，停止后真实位置立即恢复。
- 路线播放支持设定起点、途经点和终点后沿路移动，可保存路线并复用，播放过程同步到底栏和灵动岛。
- 收藏地点支持搜索排序、地图链接解析以及备份导入导出；随机扰动半径和定位精度可在设置中调整。
- 设置页按运行模式拆分；免费签名到期会显示提醒和倒计时；第三方模式可在本机提供模块订阅服务。

## 兼容性说明

- Live Activity 需要 iOS 16.2 及以上；更低系统仍可使用 App 内定点与路线功能。
- 开发者隧道模式需要 iOS 18 及以上，并依赖 LocalDevVPN 与一次电脑配对。
- iOS 27 beta 6 起系统禁止对 `gs-loc.apple.com` 进行 MITM 拦截，APP 模式与第三方代理模式在该版本及之后的 beta 上暂时不可用。

## 自签安装

- Release 附件为未签名 IPA，安装前需要自行签名。
- 可使用免费 Apple ID 和 Impactor 完成签名安装，无需付费开发者账号。
- 签名时请保留 Bundle ID `com.paopaolabs.location-spoofer`、App Group `group.com.paopaolabs.location-spoofer` 及原有 entitlements。
- 免费 Apple ID 签名通常只有 7 天有效期，到期后需要重新签名安装。
