# v1.1.1.2

发布日期：2026-10-06

## 主要更新

- 首页搜索下方改为坐标与「定点／路线」入口栏：定点打开最近／收藏浮窗，路线打开点位／已存路线浮窗；点击坐标可切换并复制国内／国际坐标。图层切换移到坐标旁。
- 底部卡片保留状态、参数摘要和执行按钮；路线参数和真实走动按需打开浮窗。上下区域限制高度，内容过多时内部滚动，避开地图中心选点。
- 小屏或大字号空间不足时，上方浮窗临时替代顶部入口区，关闭后恢复。
- 切入 APP 或开发者隧道前，等待已发出的第三方请求收尾，再按坐标证据决定是否清理。仅切换模式、完成配置、检测失败或查询到无坐标，不会凭空产生清理义务。
- 旧版待清理标记混合了真实写入和清理失败。首次升级时无法核实的历史状态会单独说明；若从未向第三方同步过坐标，可选择「从未同步，直接切换」移除旧标记，此操作不会覆盖新检测到的坐标或写入记录。

## 兼容性说明

- Live Activity 需要 iOS 16.2 及以上；更低系统仍可使用 App 内定点与路线功能。
- 开发者隧道模式需要 iOS 18 及以上，并依赖 LocalDevVPN 与一次电脑配对。这台手机必须作为客户端连着 Wi-Fi（无公网也可以）；只开流量或自己开热点通常连不上。
- iOS 27 beta 6 起系统禁止对 `gs-loc.apple.com` 进行 MITM 拦截，APP 模式与第三方代理模式在该版本及之后不可用。请改用开发者隧道模式。

## 自签安装

- Release 附件为未签名 IPA，安装前需要自行签名。
- 可使用免费 Apple ID 和 Impactor 完成签名安装，无需付费开发者账号。
- 签名时请保留 Bundle ID `com.paopaolabs.location-spoofer`、App Group `group.com.paopaolabs.location-spoofer` 及原有 entitlements。
- 免费 Apple ID 签名通常只有 7 天有效期，到期后需要重新签名安装。
